# SkillBridge 🚀

**Bridging the gap between learning and job readiness.**

SkillBridge is an AI-powered learning platform designed to help students develop technical skills and prepare for real-world job opportunities. It combines structured learning resources, hands-on practice, assessments, projects, and interview preparation in one place.

## ✨ Features

- 📚 **Structured Learning:** Learn technologies through beginner, intermediate, and advanced levels.
- 💻 **Practice Sessions:** Strengthen programming skills through practical exercises.
- 📝 **Mock Tests:** Test your knowledge and assess your understanding.
- 🛠️ **Project-Based Learning:** Apply concepts through practical projects.
- 🗺️ **Learning Roadmaps:** Follow structured paths to improve your skills.
- 🎯 **Interview Preparation:** Prepare for technical interviews and job opportunities.
- 🤖 **AI Assistant:** Get help with doubts and learning questions.

## 🧰 Tech Stack

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Python, Flask
- **Database:** Microsoft SQL Server
- **Database Management:** SQL Server Management Studio (SSMS)
- **AI Integration:** Google Gemini API

## ⚙️ Setup and Installation

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
cd SkillBridge
```

### 2. Create a virtual environment

```bash
python -m venv .venv
```

Activate it on Windows:

```powershell
.\.venv\Scripts\Activate.ps1
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Configure environment variables

Create a local `.env` file or configure the required environment variables in your terminal. Add your Gemini API key and database settings as needed.

**Never commit `.env` files, API keys, or database passwords to GitHub.**

### 5. Configure the database

Set up Microsoft SQL Server, create the required SkillBridge database and tables, and configure the connection settings.

### 6. Run the application

Start the Flask backend using the correct entry-point file and run the frontend using a local development server.

*Backend commands and configuration depend on the project's current file structure.*
